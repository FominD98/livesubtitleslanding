Slack 실시간 캡션 및 인공지능 실시간 번역

Slack Huddles는 빠른 음성 확인을 위한 대표 방식이 되었지만, 국제 팀에는 익숙한 문제가 생깁니다. 빠른 말, 섞인 억양, 기록 부재입니다. Slack 실시간 캡션은 이 문제를 해결합니다. Live Subtitles는 모든 Huddle 또는 통화 옆에서 실행되며 실시간 캡션을 화면에 직접 표시합니다.

Slack에 실시간 캡션을 추가하는 3단계

  1. Microsoft Store에서 Live Subtitles 다운로드 후 앱을 실행합니다.
  2. 소스로 "시스템 오디오"를 선택합니다. 마이크 없이 Slack 오디오를 캡처합니다.
  3. Huddle을 시작하면 Slack 위에 유지되는 떠 있는 오버레이에 캡션이 자동으로 표시됩니다.

Slack Huddles에 실시간 캡션이 필요한 이유

Zoom이나 Teams와 달리 Slack Huddles는 내장 실시간 캡션이나 전사를 제공하지 않습니다. 유럽, 아시아, 라틴아메리카에 흩어진 원격 팀에서는 10분짜리 Huddle 하나가 핵심 단어를 놓쳤다는 이유만으로 10개의 후속 메시지를 만들 수 있습니다. 인공지능 실시간 캡션은 음성을 텍스트처럼 훑어볼 수 있게 만들어 팀이 속도를 늦추지 않고 같은 이해를 유지하도록 돕습니다.

  • 비원어민은 발표자를 끊지 않고 자신의 속도로 따라갈 수 있습니다.
  • 청력 손실이 있는 팀원은 접근성 플러그인 없이 Huddle에 온전히 참여할 수 있습니다.
  • 빠른 말, 강한 억양, 낮은 품질의 오디오 연결이 읽을 수 있는 텍스트가 됩니다.
  • 관리자 승인이나 Slack 앱 설치가 필요하지 않으며 운영 체제 수준에서 작동합니다.

다국어 Slack 통화를 위한 이중 자막

Live Subtitles는 이중 자막 모드를 지원합니다. 원문 음성은 위 줄에, 선택한 번역 언어는 아래 줄에 동시에 표시됩니다. 팀은 스페인어로 말하지만 회사 언어가 영어라면 두 언어를 실시간으로 모두 볼 수 있습니다. 이 기능은 Slack Huddles, Slack 통화, 재생하는 모든 Slack 오디오 또는 영상 메시지에서 작동합니다.

지원 범위: 스페인어, 프랑스어, 독일어, 일본어, 중국어, 한국어, 러시아어, 아랍어, 힌디어, 포르투갈어, 폴란드어, 네덜란드어, 터키어, 우크라이나어를 포함한 50개 이상의 인식 언어와 50개 이상의 번역 대상 언어.

모든 Slack 기능과 작동

Live Subtitles는 시스템 오디오를 캡처하므로 Slack이 소리를 전달하는 방식과 관계없이 작동합니다.

  • Slack Huddles 일대일 및 그룹
  • Slack 영상 통화
  • 재생하는 Slack 오디오 클립과 음성 메시지
  • Slack 짧은 영상 녹화
  • 외부 파트너와의 Slack Connect 통화

Slack 봇도, 접속 키도, 워크스페이스 관리자 승인도 필요하지 않습니다. 설치하고 시스템 오디오를 선택하기만 하면 모든 Slack 대화가 읽을 수 있는 형태가 됩니다.

원격 및 비동기 팀을 위한 Slack 캡션

Slack 중심 팀은 동기식 Huddles와 비동기 음성 클립을 함께 사용하는 경우가 많습니다. Live Subtitles는 두 가지를 모두 지원합니다. Huddle 중에는 실시간 캡션을 표시하고, 녹음된 클립을 다시 재생할 때도 실시간 캡션을 표시합니다. 별도의 업무 흐름 변경 없이 전체 Slack 오디오 계층을 검색 가능하고 접근 가능한 형태로 만듭니다.
