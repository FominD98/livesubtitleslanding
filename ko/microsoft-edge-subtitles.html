홈 / Microsoft Edge 실시간 캡션

Microsoft Edge 실시간 캡션 및 인공지능 브라우저 자막

Microsoft Edge는 모든 Windows 11 PC의 기본 브라우저이며 온라인 영상, 웹 회의, 팟캐스트 스트림을 매일 수십억 시간 소비하는 공간입니다. Edge에도 자체 Live Captions 기능이 있지만 대부분의 사용자에게는 영어 전용이고, 번역을 제공하지 않으며, 모든 브라우저 업데이트에서 완전히 안정적이지는 않습니다. Live Subtitles의 Microsoft Edge 실시간 캡션은 다른 방식으로 접근합니다. 브라우저 밖에서 작동하며 Edge가 재생하는 모든 것을 50개 이상의 언어로 캡션 처리하고 선택적으로 실시간 번역을 제공하며, 화면 어디에나 고정할 수 있는 작은 떠 있는 오버레이로 표시합니다.

Microsoft Edge에 실시간 캡션을 추가하는 3단계

  1. Microsoft Store에서 Live Subtitles를 다운로드하고 앱을 실행합니다.
  2. "시스템 오디오"를 선택합니다. 브라우저 확장 프로그램 없이 Edge의 모든 탭 오디오를 캡처합니다.
  3. Edge에서 영상, 오디오, 웹 통화를 재생하면 떠 있는 오버레이에 캡션이 즉시 표시됩니다.

인기 사이트뿐 아니라 모든 사이트에 캡션

Edge의 기본 Live Captions 기능은 주류 영어 영상 사이트에서는 잘 작동하지만, 웹의 긴 꼬리 영역에서는 캡션이 자주 깨집니다. 틈새 언어 뉴스, 지역 대학 강의 포털, 작은 팟캐스트 플레이어, 기업 사이트의 삽입 영상, 보관 방송 미디어가 그렇습니다. Live Subtitles는 원본 사이트에 신경 쓰지 않습니다. Windows가 오디오 믹서를 통해 재생하는 소리를 읽기 때문에 Edge에서 소리를 내는 모든 탭이 같은 방식으로 자막 처리됩니다.

  • YouTube, Vimeo, Dailymotion 및 기타 영상 플랫폼.
  • 모든 언어의 삽입 영상 보도가 있는 뉴스 사이트.
  • 대학 강의 포털과 주문형 교육 플랫폼.
  • 웹 기반 회의 플랫폼(Zoom Web, Meet, Webex, Teams 웹 클라이언트).
  • 팟캐스트 웹 플레이어와 삽입 오디오 플레이어.
  • 라디오 및 TV 스트림용 실시간 방송 포털.

브라우저 플러그인 없는 다국어 웹 영상

웹에서 프랑스어 뉴스 방송, 독일어 시사 분석, 한국어 학술 강연, 일본어 기술 컨퍼런스 스트림을 보려면 보통 운이 필요하거나 작업이 필요합니다. 사이트에 좋은 자막이 있기를 바라거나, 온라인에서 자막 파일을 찾아 수동으로 맞춰야 합니다. Live Subtitles의 이중 자막 모드는 이 둘을 대신합니다. 원문 음성은 위 줄에, 더 익숙한 언어의 번역은 아래 줄에 표시되며 Edge가 재생하는 무엇 위에서도 실시간으로 업데이트됩니다.

Edge Workspaces, InPrivate, 분할 화면 지원

Edge는 공유 브라우징 세션을 위한 Workspaces, 세로 탭, 두 탭을 나란히 보는 분할 화면, 여러 프로필, InPrivate 창 등 긴 고급 기능 목록을 제공합니다. 이런 기능은 브라우저 확장 기반 캡션 도구를 혼란스럽게 만들 수 있습니다. 확장 프로그램이 항상 일관되게 로드되지 않을 수 있기 때문입니다. Live Subtitles는 영향을 받지 않습니다. 같은 오디오 출력을 읽는 별도 Windows 앱이므로 모든 Edge 기능, 모든 프로필, 모든 창 모드에서 동일하게 작동합니다.

개인정보: 브라우저 데이터 접근 없음

Live Subtitles는 Edge 확장 프로그램이 아니므로 방문 기록, 쿠키, 비밀번호 또는 기타 브라우저 데이터를 볼 수 없습니다. 탭의 URL을 읽을 수 없고, 입력 양식 내용을 볼 수 없으며, 페이지 구조를 검사할 수도 없습니다. 들어오는 데이터는 스피커를 구동하는 것과 같은 오디오 출력 스트림뿐이고, 나가는 데이터는 화면에 표시되는 전사문뿐입니다. 지원되는 인식 및 번역 언어에는 영어, 스페인어, 프랑스어, 독일어, 이탈리아어, 일본어, 한국어, 표준 중국어, 러시아어, 아랍어, 힌디어, 포르투갈어, 폴란드어, 네덜란드어, 터키어, 우크라이나어 등 50개 이상이 포함됩니다.

자주 묻는 질문

Live Subtitles는 Microsoft Edge와 작동하나요?
네. Edge의 모든 오디오 소스가 브라우저 확장 프로그램 없이 자막 처리됩니다.

Edge의 기본 Live Captions와 다른가요?
네. Edge 기능은 대부분의 사용자에게 영어 전용입니다. Live Subtitles는 50개 이상의 언어와 이중 언어 번역을 지원합니다.

모든 웹사이트에 캡션을 표시하나요, 아니면 특정 플랫폼만 지원하나요?
모든 웹사이트를 지원합니다. 모든 탭에서 재생되는 오디오가 자막 처리됩니다.

Edge InPrivate와 Edge Workspaces에서도 작동하나요?
네. 모든 Edge 프로필, 창, 모드에서 동일하게 작동합니다.
