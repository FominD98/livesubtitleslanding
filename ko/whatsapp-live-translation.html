WhatsApp 실시간 번역 및 인공지능 통화 자막

20억 명이 넘는 사람이 WhatsApp을 사용하며, 많은 통화에서 언어가 가장 큰 장벽입니다. WhatsApp 실시간 번역은 어떤 통화든 내 언어로 따라갈 수 있게 합니다. 인공지능이 오디오를 실시간으로 캡처하고 Windows 화면에 캡션과 번역을 직접 표시합니다.

WhatsApp에 실시간 번역을 추가하는 3단계

  1. Microsoft Store에서 Live Subtitles 다운로드 후 앱을 실행합니다.
  2. "시스템 오디오"를 선택합니다. 앱이 상대방의 음성을 스피커에서 캡처합니다.
  3. WhatsApp 통화를 걸거나 받으면 WhatsApp 창 위에 실시간 캡션이 자동으로 표시됩니다.

WhatsApp 통화에 실시간 번역이 필요한 이유

Windows의 WhatsApp Desktop에는 내장 실시간 캡션이나 번역이 없습니다. 해외 가족, 국제 고객, 다국어 고객 지원팀과 통화할 때 한 단어를 놓치는 것만으로도 합의가 오해되거나 통화 상대가 답답함을 느낄 수 있습니다. 인공지능 실시간 캡션은 WhatsApp 작동 방식을 바꾸지 않고 이 간극을 닫습니다.

  • 언어 장벽을 넘는 가족 통화에서 다른 언어를 말하는 친척을 이해합니다.
  • 국제 비즈니스 통화에서 반복 요청으로 속도를 늦추지 않고 고객과 공급업체를 따라갑니다.
  • 다국어 고객 지원에서 상담원이 모든 언어의 통화를 캡션으로 따라갑니다.
  • 억양이 있거나 빠른 말이 있는 통화에서 캡션이 들은 내용을 확인하는 두 번째 채널을 제공합니다.

이중 자막: 원문 언어와 번역을 동시에

Live Subtitles는 이중 자막 모드를 지원합니다. 위 줄에는 상대방 언어의 원문 음성 전사가 표시됩니다. 아래 줄에는 선택한 번역이 실시간으로 표시됩니다. 두 줄이 동시에 업데이트되므로 지연 없이 정확한 말과 의미를 함께 따라갈 수 있습니다.

언어를 배우는 중이라 이해도를 확인하고 싶을 때나, 한 언어만 쓰는 상대와 서로 다른 언어로 소통해야 할 때 특히 유용합니다.

WhatsApp 음성 및 영상 통화와 작동

Live Subtitles는 시스템 오디오 캡처를 사용하므로 Windows 스피커로 나오는 모든 오디오와 작동합니다.

  • WhatsApp Desktop 음성 통화
  • WhatsApp Desktop 영상 통화
  • 브라우저의 WhatsApp Web 통화
  • 재생하는 WhatsApp 음성 메시지

WhatsApp 플러그인도, 접속 권한도, WhatsApp 내부 권한도 필요하지 않습니다. 상대방 쪽에서는 아무 변화도 보이지 않습니다.
