Webex 실시간 캡션 및 인공지능 실시간 번역

Cisco Webex는 기업 정보기술 팀, 규제 산업, 대규모 웨비나가 선택하는 플랫폼입니다. 하지만 내장 캡션은 참석자에게 제공되지 않거나 진행자 설정에 잠겨 있거나 무료 계정에는 아예 없는 경우가 많습니다. Webex 실시간 캡션은 이 문제를 바꿉니다. Live Subtitles는 모든 Webex 회의 또는 웨비나 옆에서 실행되며, 봇이나 플러그인이나 Cisco 정보기술 승인 없이 Windows 화면에 실시간 인공지능 캡션을 직접 표시합니다.

Webex에 실시간 캡션을 추가하는 3단계

  1. Microsoft Store에서 Live Subtitles 다운로드 후 앱을 실행합니다.
  2. 소스로 "시스템 오디오"를 선택합니다. 마이크 없이 Webex 오디오를 자동으로 캡처합니다.
  3. Webex 회의 또는 웨비나에 참여하면 모든 창 위에 유지되는 떠 있는 오버레이에 캡션이 표시됩니다.

기업 Webex 사용자에게 독립적인 실시간 캡션이 필요한 이유

기존 회의 도구에서 Webex로 표준화한 많은 조직은 같은 접근성 간극을 겪습니다. Webex의 기본 인공지능 캡션은 특정 구독 등급, 진행자의 활성화, 경우에 따라 관리자의 Control Hub 구성이 필요합니다. 특히 규제 산업이나 해외 지사에 있는 개별 참석자는 자신의 힘으로 캡션을 안정적으로 켤 방법이 없는 경우가 많습니다.

Live Subtitles는 이 문제를 사용자 장치 수준에서 해결합니다. 시스템 오디오를 읽기 때문에 Webex 진행자가 무엇을 설정했는지와 완전히 독립적으로 작동합니다.

  • 회의 참가자 목록에 나타나는 Webex 봇이 없습니다.
  • Control Hub나 사이트 관리자 설정을 바꿀 필요가 없습니다.
  • Cisco 정보기술 티켓을 만들 필요가 없습니다. Microsoft Store에서 앱을 설치하면 바로 작동합니다.
  • 진행자의 요금제와 관계없이 Webex Meetings, Webex Webinars, Webex Events에 유용합니다.

국제 Webex 웨비나를 위한 실시간 번역

대규모 기업 웨비나는 여러 나라의 청중을 자주 끌어들입니다. 영어로 진행되는 제품 출시나 전사 공유 회의에 일본어, 스페인어, 독일어, 아랍어가 모국어인 동료나 고객이 참석할 수 있습니다. Live Subtitles의 이중 자막 모드는 이를 처리합니다. 원문 음성은 위 줄에, 선택한 번역 언어는 아래 줄에 표시되며 지연 없이 동시에 나타납니다.

텍스트 기반 질의응답만 가능하고 참석자가 발표자에게 다시 말해 달라고 요청하기 어려운 Webex Events 형식의 웨비나에서 특히 가치가 큽니다. 자신의 언어로 따라가면 그 마찰이 사라집니다.

지원 범위: 스페인어, 프랑스어, 독일어, 이탈리아어, 일본어, 중국어, 한국어, 러시아어, 아랍어, 힌디어, 포르투갈어, 폴란드어, 네덜란드어, 터키어, 우크라이나어를 포함한 50개 이상의 음성 인식 언어와 50개 이상의 번역 대상 언어.

모든 Webex 세션 유형과 작동

Live Subtitles는 시스템 오디오를 캡처하므로 세션 유형별 설정 없이 모든 종류의 Webex 세션과 작동합니다.

  • Webex Meetings 예약 회의와 Personal Room
  • Webex Webinars 및 Webex Events
  • Webex Training 세션
  • Webex 앱의 일대일 및 그룹 통화
  • 컴퓨터에서 재생하는 녹화된 Webex 세션

떠 있는 오버레이는 Webex 창 위에 유지되므로 애플리케이션을 전환하지 않아도 캡션이 항상 보입니다.

정보기술 부서가 관리하는 Webex 환경을 위한 실용적인 선택

Webex를 표준 화상 회의 플랫폼으로 배포한 기업 정보기술 팀에서도 직원의 접근성 요구가 중앙에서 라이선스나 구성을 마친 기능과 항상 일치하지는 않습니다. Live Subtitles는 개별 직원에게 셀프서비스 해결책을 제공합니다. 그룹 정책 변경, 가상 사설망 예외, 표준 Microsoft Store 애플리케이션을 넘어선 승인 소프트웨어 등록이 필요하지 않습니다. 사용자 장치 안에서 동작하며 회의 오디오를 회의 주최자나 정보기술 부서가 제어하는 서버로 전송하지 않습니다. 오디오는 로컬에서 처리되거나 사용자가 선택한 음성 인식 제공자를 통해 처리됩니다.
