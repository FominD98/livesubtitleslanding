Windows의 모든 앱에 실시간 캡션 추가

대부분의 실시간 캡션 도구는 지원 앱 목록에서 시작합니다. 앱이 목록에 있으면 캡션이 작동하고, 없으면 공급업체가 연동을 추가할 때까지 기다려야 합니다. Live Subtitles는 그 모델을 뒤집습니다. 개별 앱과 연동하지 않고 Windows 오디오 믹서 수준에 위치해 PC가 스피커나 헤드폰으로 재생하는 모든 소리를 자막 처리합니다. 그 결과 지원 앱 목록은 사실상 오디오를 내는 모든 Windows 애플리케이션이 됩니다. Live Subtitles가 처음 만들어진 뒤에 나온 앱도 포함됩니다. 하나의 떠 있는 오버레이로 Windows의 모든 앱에 실시간 캡션을 추가하고, 50개 이상의 언어와 선택적 실시간 번역을 사용할 수 있습니다.

모든 앱에 실시간 캡션을 추가하는 3단계

  1. Microsoft Store에서 Live Subtitles를 다운로드하고 앱을 실행합니다.
  2. "시스템 오디오"를 선택합니다. PC에서 실행 중인 모든 앱의 오디오를 캡처합니다.
  3. 소리를 내는 아무 앱이나 사용하면 모든 창 위에 유지되는 떠 있는 오버레이에 캡션이 표시됩니다.

한 번 설치하면 모든 앱에 캡션 표시

Live Subtitles는 한 번만 설정합니다. 초기 설정에서 인식 언어를 고르고, 필요하면 번역 언어를 고르고, 원하는 위치에 오버레이를 놓으면 더 이상 설정할 것이 없습니다. 그 뒤부터 모든 오디오 소스가 자동으로 자막 처리됩니다.

  • 영상 회의 도구 - Zoom, Microsoft Teams, Google Meet, Webex, Skype, GoToMeeting, BlueJeans.
  • 모든 탭에서 영상이나 오디오를 재생하는 웹 브라우저 - Edge, Chrome, Firefox, Brave, Opera.
  • 스트리밍 서비스 - Netflix, Disney+, Prime Video, Hulu, Apple TV+, HBO Max.
  • 통화 기능이 있는 메시징 앱 - WhatsApp, Telegram, Viber, Signal, Discord, Slack, LINE, WeChat.
  • 영상 및 오디오 플레이어 - VLC, Windows Media Player, MPC-HC, Plex, Spotify, Apple Music.
  • 팟캐스트 앱과 오디오북 클라이언트.
  • Steam 게임 및 Windows의 다른 게임 스토어 - Epic, GOG, EA, Battle.net, Xbox PC.
  • 웹 기반 학습 플랫폼 - Coursera, Udemy, Khan Academy, edX, Google Classroom.
  • 실시간 방송 플랫폼 - Twitch, YouTube Live, Facebook Live, Instagram Live, Restream.
  • 사내 기업 도구 - 맞춤 영상 포털, 이러닝 플랫폼, 교육 앱.

시스템 전체 방식이 앱별 연동보다 나은 이유

앱별 캡션 연동에는 세 가지 구조적 문제가 있습니다. 첫째는 범위입니다. 공급업체는 자신들이 코드를 작성한 앱만 지원하므로 틈새 앱, 사내 기업 도구, 인디 소프트웨어의 긴 꼬리는 영구적으로 빠집니다. 둘째는 업데이트 취약성입니다. 앱이 API를 업데이트하거나 오디오 라우팅을 바꾸면 공급업체가 패치할 때까지 연동이 깨집니다. 셋째는 권한 부담입니다. 많은 연동은 IT 관리자 승인, 계정 수준 OAuth, 플랫폼 쪽 기능 플래그를 요구하며 개인 사용자가 직접 켤 수 없습니다.

Live Subtitles는 운영 체제 오디오 믹서 수준에서 작동해 세 문제를 모두 피합니다. 모든 오디오 앱이 같은 믹서를 통과하므로 범위는 보편적입니다. 믹서는 안정적인 Windows API이므로 업데이트 취약성은 거의 없습니다. 사용자는 자신의 PC에서 오디오를 들을 권한을 이미 갖고 있으므로 권한 부담은 없습니다.

모든 앱에서 번역, 접근성, 언어 학습

이중 자막 모드도 시스템 전체에서 작동합니다. Zoom에서도, Steam에서도, VLC에서도, Telegram에서도 같은 방식입니다. 예를 들어 원문 일본어를 위에, 영어를 아래에 표시하도록 설정하면 Windows PC의 모든 일본어 오디오 소스가 자동으로 전사되고 번역됩니다. Spotify의 일본어 팟캐스트, Discord의 일본어 음성 채팅, 브라우저의 일본어 TV 방송, Steam의 일본 RPG까지 모두 같은 설정으로 작동합니다. 지원되는 인식 및 번역 언어에는 영어, 스페인어, 프랑스어, 독일어, 이탈리아어, 일본어, 한국어, 표준 중국어, 러시아어, 아랍어, 힌디어, 포르투갈어, 폴란드어, 네덜란드어, 터키어, 우크라이나어, 인도네시아어 등 50개 이상이 포함됩니다.
