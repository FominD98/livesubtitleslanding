Живі субтитри Edge і ШІ-субтитри браузера

Microsoft Edge - стандартний браузер на кожному ПК з Windows 11 і щоденний дім для мільярдів годин онлайн-відео, вебзустрічей і подкастів. Edge має власну функцію живих субтитрів, але для більшості користувачів вона англомовна, не перекладає й не завжди стабільно переживає оновлення браузера. Живі субтитри Edge через Live Subtitles працюють інакше: вони повністю поза браузером, субтитрують усе, що відтворює Edge, 50+ мовами з додатковим перекладом у реальному часі та показують текст у невеликому плаваючому оверлеї, який можна закріпити будь-де на екрані.

Як додати живі субтитри до Edge за 3 кроки

  1. Завантажте Live Subtitles із Microsoft Store і запустіть програму.
  2. Виберіть «Системний звук» - програма захоплює аудіо з будь-якої вкладки Edge без розширення браузера.
  3. Відтворіть будь-яке відео, аудіо або вебдзвінок в Edge - субтитри миттєво з'являться у плаваючому оверлеї.

Субтитри для кожного сайту, а не лише популярних

Вбудована функція живих субтитрів Edge добре працює на великих англомовних відеосайтах, але довгий хвіст вебу - нішеві мовні новини, регіональні університетські портали, менші подкаст-плеєри, вбудоване відео на корпоративних сайтах, архівні трансляції - саме там субтитри найчастіше ламаються. Live Subtitles не залежить від сайту-джерела. Програма читає те, що Windows відтворює через аудіомікшер, тому будь-яка вкладка Edge зі звуком субтитрується однаково:

  • YouTube, Vimeo, Dailymotion та інші відеоплатформи.
  • Новинні сайти з вбудованими відеорепортажами будь-якою мовою.
  • Університетські лекційні портали та платформи курсів на вимогу.
  • Вебверсії платформ зустрічей: Zoom Web, Meet, Webex, вебклієнт Teams.
  • Подкаст-плеєри та вбудовані аудіоплеєри.
  • Портали прямих радіо- й телетрансляцій.

Багатомовне вебвідео без плагінів браузера

Перегляд французького випуску новин, німецької політичної аналітики, корейської академічної доповіді або японської технічної конференції в інтернеті зазвичай вимагає або везіння, якщо сайт має пристойні субтитри, або ручної роботи з пошуку й синхронізації файлу субтитрів. Режим подвійних субтитрів Live Subtitles замінює обидва варіанти: оригінальне мовлення у верхньому рядку, переклад сильнішою для вас мовою в нижньому, і обидва оновлюються в реальному часі поверх того, що відтворює Edge.

Працює з Edge Workspaces, InPrivate і розділеним екраном

Edge має багато розширених функцій: Workspaces для спільних сеансів перегляду, вертикальні вкладки, розділений екран для двох вкладок поруч, кілька профілів, вікна InPrivate. Усі вони можуть плутати інструменти субтитрів на базі розширень, бо розширення може завантажуватися непослідовно. Live Subtitles не залежить від цього: це окрема програма Windows, яка читає той самий аудіовихід, тому працює однаково в кожній функції Edge, кожному профілі й кожному режимі вікна.

Приватність: без доступу до даних браузера

Оскільки Live Subtitles не є розширенням Edge, програма не має доступу до історії перегляду, файлів cookie, паролів або інших даних браузера. Вона не може прочитати адресу вкладки, не бачить вмісту форм і не інспектує структуру сторінки. Єдині вхідні дані - вихідний аудіопотік, той самий, що подається на динаміки, а єдиний результат - транскрипт на вашому екрані. Підтримувані мови розпізнавання й перекладу включають англійську, іспанську, французьку, німецьку, італійську, японську, корейську, китайську, російську, арабську, гінді, португальську, польську, нідерландську, турецьку й українську - серед понад 50 мов загалом.

Чи працює Live Subtitles з Microsoft Edge?
Так. Кожне аудіоджерело в Edge субтитрується без розширення браузера.

Чим це відрізняється від вбудованих живих субтитрів Edge?
Функція Edge для більшості користувачів працює лише англійською; Live Subtitles підтримує 50+ мов і двомовний переклад.

Чи субтитрує це всі сайти або лише конкретні платформи?
Усі сайти: усе, що відтворює аудіо в будь-якій вкладці, субтитрується.

Чи працює це в Edge InPrivate і Edge Workspaces?
Так. Субтитри працюють однаково в усіх профілях, вікнах і режимах Edge.
