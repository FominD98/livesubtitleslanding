Субтитры Edge и ИИ-субтитры в браузере

Microsoft Edge — браузер по умолчанию на каждом ПК с Windows 11 и ежедневный дом миллиардов часов онлайн-видео, веб-встреч и потоков подкастов. У Edge есть собственная функция Live Captions, но для большинства пользователей она только английская, не переводит и не выживает невредимой при каждом обновлении браузера. Субтитры Edge через Live Subtitles используют другой подход: они находятся полностью вне браузера, субтитруя все, что воспроизводит Edge, на 50+ языках с опциональным переводом в реальном времени, все из небольшого плавающего оверлея, который можно закрепить в любом месте экрана.

Как добавить субтитры в Edge за 3 шага

  1. Скачайте Live Subtitles из Microsoft Store и запустите приложение.
  2. Выберите «Системный звук» — захватывает звук с любой вкладки в Edge без расширения для браузера.
  3. Воспроизведите любое видео, аудио или веб-звонок в Edge — субтитры появятся мгновенно в плавающем оверлее.

Субтитры для каждого сайта, не только популярного

Встроенная функция Live Captions Edge хорошо работает на основных англоязычных видеосайтах, но длинный хвост веба — нишевые новости на разных языках, региональные порталы университетских лекций, мелкие плееры подкастов, встроенное видео на корпоративных сайтах, архивные трансляционные медиа — это там, где субтитрование стабильно ломается. Live Subtitles все равно, какой исходный сайт. Он считывает то, что Windows воспроизводит через аудио-микшер, поэтому любая вкладка в Edge, которая производит звук, субтитруется одинаково:

  • YouTube, Vimeo, Dailymotion и другие видеоплатформы.
  • Новостные сайты со встроенными видеорепортажами на любом языке.
  • Порталы университетских лекций и платформы курсов по запросу.
  • Веб-платформы для встреч (Zoom Web, Meet, Webex, веб-клиент Teams).
  • Веб-плееры подкастов и встроенные аудиоплееры.
  • Порталы прямых трансляций для радио и ТВ потоков.

Многоязычное веб-видео без плагинов браузера

Просмотр французского новостного выпуска, немецкого политического анализа, корейского академического доклада или японского технологического конференц-стрима в вебе традиционно требует либо удачи (на сайте есть приличные субтитры), либо работы (найти .srt онлайн и синхронизировать вручную). Режим двойных субтитров Live Subtitles заменяет оба: оригинальная речь на верхней строке, перевод на более сильный для вас язык на нижней строке, оба обновляются в реальном времени поверх того, что воспроизводит Edge.

Работает с Edge Workspaces, InPrivate и разделенным экраном

Edge предлагает длинный список продвинутых функций — Workspaces для совместного использования сессий просмотра, вертикальные вкладки, разделенный экран для двух вкладок рядом, несколько профилей, окна InPrivate. Каждая из них может сбить с толку инструменты субтитров на основе расширений, потому что расширение может не загружаться последовательно. Live Subtitles это не затрагивает: это отдельное приложение для Windows, считывающее тот же аудио-выход, поэтому оно работает одинаково в каждой функции Edge, каждом профиле и каждом режиме окна.

Приватность: нет доступа к данным браузера

Поскольку Live Subtitles не является расширением Edge, у него нет доступа к вашей истории просмотра, файлам cookie, паролям или другим данным на стороне браузера. Он не может читать URL вкладки; он не может видеть содержимое форм; он не может ничего инспектировать в DOM. Единственные данные, которые поступают в него, — это аудио-выходной поток — тот же поток, который питает ваши динамики — а единственные данные, которые поступают наружу, — это итоговый транскрипт, показываемый на вашем экране. Поддерживаемые языки распознавания и перевода включают английский, испанский, французский, немецкий, итальянский, японский, корейский, мандаринский китайский, русский, арабский, хинди, португальский, польский, нидерландский, турецкий и украинский — среди 50+ всего.

Частые вопросы

Работает ли Live Subtitles с Microsoft Edge?
Да — каждый источник звука в Edge субтитруется без какого-либо расширения для браузера.

Чем это отличается от встроенных Live Captions в Edge?
Встроенная функция Edge для большинства пользователей только английская; Live Subtitles поддерживает 50+ языков и двуязычный перевод.

Субтитрует ли он все веб-сайты или только конкретные платформы?
Все веб-сайты — все, что воспроизводит звук на любой вкладке, субтитруется.

Работает ли он в InPrivate Edge и Edge Workspaces?
Да. Субтитры работают одинаково во всех профилях, окнах и режимах Edge.
