WhatsApp 实时翻译与人工智能通话字幕

全球超过 20 亿人使用 WhatsApp，对其中许多人来说，语言是通话中的主要障碍。WhatsApp 实时翻译让你用自己的语言跟上任何通话，人工智能会实时捕获音频，并直接在 Windows 屏幕上显示字幕和译文。

如何通过 3 个步骤为 WhatsApp 添加实时翻译

  1. 从 Microsoft Store 下载 Live Subtitles 并启动应用。
  2. 选择“系统音频”，应用会从扬声器捕获对方的声音。
  3. 拨打或接听 WhatsApp 通话，实时字幕会自动显示在 WhatsApp 窗口上方。

为什么 WhatsApp 通话需要实时翻译

Windows 上的 WhatsApp Desktop 没有内置实时字幕或翻译。无论是与海外家人通话、联系国际客户，还是处理多语言客户支持，漏掉一个词都可能造成误解或让对方受挫。人工智能实时字幕可以弥补这个缺口，而无需改变 WhatsApp 的工作方式。

  • 跨语言家庭通话：听懂使用另一种语言的亲人。
  • 国际商务通话：跟上客户和供应商，无需频繁要求重复。
  • 多语言客户支持：客服人员可通过字幕跟上任意语言通话。
  • 口音较重或语速较快的通话：字幕提供第二条确认通道。

双语字幕：原始语言和译文同时显示

Live Subtitles 支持双语字幕模式。上方一行显示对方语言的原始转写，下方一行实时显示你选择的译文。两行会同步更新，因此你可以同时跟上原话和含义，不必等待。

当你正在学习一门语言并希望确认理解，或需要与只会一种语言的联系人沟通时，这一点尤其有用。

适用于 WhatsApp 语音和视频通话

Live Subtitles 使用系统音频捕获，因此可处理任何通过 Windows 扬声器播放的音频：

  • WhatsApp Desktop 语音通话
  • WhatsApp Desktop 视频通话
  • 浏览器中的 WhatsApp Web 通话
  • 播放中的 WhatsApp 语音消息

无需 WhatsApp 插件、无需接口访问，也无需在 WhatsApp 内授予权限。对方那一端不会看到任何不同。

WhatsApp 通话支持 50 多种语言

Live Subtitles 支持 50 多种识别语言，包括西班牙语、阿拉伯语、印地语、葡萄牙语、法语、德语、意大利语、俄语、日语、韩语、中文、土耳其语、波兰语、荷兰语、乌克兰语等。翻译目标语言覆盖同样范围。选择任意组合，例如西班牙语到英语、阿拉伯语到法语、印地语到西班牙语，双语字幕覆盖层即可立即工作。

常见问题

Live Subtitles 可以用于 Windows 上的 WhatsApp 通话吗？
可以。它会捕获系统音频，因此可自动用于 WhatsApp Desktop 通话，无需插件。

我可以实时翻译 WhatsApp 通话吗？
可以。双语字幕模式会同时显示原始语音和你选择的译文语言。

对方会知道我正在使用实时翻译吗？
不会。Live Subtitles 在你的设备本地运行，只处理你这一端的音频。

它也适用于 WhatsApp 视频通话吗？
可以，WhatsApp Desktop 中的语音和视频通话都支持。
