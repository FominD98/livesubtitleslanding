Discord 实时字幕与 AI 语音聊天翻译

Discord 以语音为核心：游戏小队打副本、学习小组使用舞台频道、社区服务器举办问答活动，以及有数百名听众的线上大会。但当队友口音很重、背景噪声盖过频道声音，或一半朋友说不同语言时，纯语音对话很难跟上。通过 Live Subtitles 添加 Discord 实时字幕可以解决这个问题：你可以为每个语音频道和舞台活动获得实时 AI 字幕，无需邀请 Discord 机器人，也无需请求服务器管理员权限。

如何通过 3 个步骤为 Discord 添加实时字幕

  1. 从 Microsoft Store 下载 Live Subtitles，并与 Discord 一起启动。
  2. 选择“系统音频”作为来源，它会捕获 Discord 语音聊天，无需麦克风或机器人设置。
  3. 加入任何语音频道、舞台或活动，字幕会立即显示在浮动覆盖层中，并保持在游戏上方。

为游戏小队和深夜副本而生

如果你曾在排位赛中因为枪声盖过耳机音量而错过关键报点，Discord 实时字幕就是为你准备的。Live Subtitles 会在浮动覆盖层中显示语音频道内所有发言的实时转写，你可以把它停靠在屏幕任意位置。它甚至会保持在全屏和无边框游戏上方，因此无需切出游戏也能读到队友的话。

常见游戏使用场景：

  • MMO 和战术射击游戏中的副本报点，错过一条指令就可能导致全队失败。
  • 国际小队中，有些队友把英语作为第二语言。
  • 主播想保留整洁的队伍语音文本记录，方便之后剪辑精彩片段。
  • 听力困难的玩家想跟上战术，而不必把耳机音量调得很高。

适用于舞台频道和服务器级活动

Discord 舞台频道常用于问答、播客式讨论、会议和大型社区活动，会把一名或多名发言者的声音广播给数百名被动听众。舞台活动通常时间长、技术内容密集，并且邀请来自多个国家的演讲者。Live Subtitles 会像处理普通语音频道一样为舞台音频加字幕，因此当口音或语速把你带离对话时，你仍然可以跟上 90 分钟的圆桌讨论。

因为 Live Subtitles 读取系统音频，它不关心听众结构：舞台上的发言者、观众席里的听众，或处理问答的主持人，通过耳机传来的每个声音都会被实时加上字幕。

面向多语言服务器和语言学习社区的翻译

Discord 已经成为语言学习社区的中心：日语学习服务器、韩国流行音乐粉丝群、西班牙语会话房间、德国桌游圈。成员希望练习目标语言，也希望彼此理解。Live Subtitles 的双字幕模式正是为此设计：原始语音显示在上方一行，你选择的译文语言显示在下方，两者同时出现。你可以一边听发音一边读意思，当理解能力跟上后再完全关闭翻译。

支持 50 多种识别语言和 50 多种翻译目标语言，包括日语、韩语、中文、西班牙语、法语、德语、意大利语、葡萄牙语、俄语、阿拉伯语、印地语、波兰语、荷兰语、土耳其语和乌克兰语。

无需机器人、无需服务器管理员、无需 Discord 插件

Live Subtitles 是独立的 Windows 应用。它不会作为机器人用户加入你的语音频道，不会出现在 Discord 成员列表中，也不需要服务器上的管理服务器或管理角色权限。这一点很重要：许多社区服务器会因隐私和信任问题直接禁止第三方语音机器人。Live Subtitles 完全绕开这一点，它只是你自己电脑上的音频读取工具，为你已经能听到的内容加字幕，通话中的其他成员无法知道你正在使用它。

我需要添加 Discord 机器人或更改服务器设置吗？
不需要。它完全在你的 Windows 电脑上运行，通话中的其他成员无法检测到。
