双语字幕 Chrome 扩展，支持 YouTube、Netflix

LiveSubtitles for Chrome 会在浏览器里任意视频的下方显示两行字幕——原文和译成你的语言的译文。点击单词即可查看含义并保存到 Anki，如果视频完全没有字幕，还能实时翻译音频。双语字幕和查词完全免费，不限次数，也无需账号。

适用于 Google Chrome、Microsoft Edge 和 Brave。来自 Live Subtitles 团队，该团队同时开发 Windows、Mac、iPhone 和 Android 版应用。

扩展能做什么

每个视频都有两行字幕

原文始终在上面，译文紧跟在下面，字体、大小、颜色和位置都可以自己设置。扩展会读取网站本身已有的字幕——YouTube 上传或自动生成的字幕、Netflix 和 Prime Video 的字幕、在线课程播放器的字幕轨，以及大多数 HTML5 视频——并实时翻译每一行。视频语言会自动识别，译文支持 39 种语言。想用自己的字幕文件？也可以把 .srt 或 .vtt 字幕文件加载到任意视频上。

点击单词即可学习

把鼠标悬停或点击字幕中的任意单词，就会打开一张卡片，显示这个词在当前语境中的译文、词典释义、发音和例句。划选多个单词可以翻译整个短语或习语。如果还是看不懂，AI 讲解会用你的语言拆解语法、习语或俚语。听的同时，正在说的单词会高亮显示，让耳朵和眼睛始终对上同一个地方。

视频旁的互动文稿

打开文稿即可看到整段视频的文字版，逐行配有译文。可以搜索内容，点击某一行跳回对应时刻，还能用学习快捷键：A 上一行，S 重复，D 下一行，Q 每行结束后暂停。这是啃一节信息密集的讲座，或者一段只听懂一半的情节时最快的方法。

没有字幕时的实时翻译

很多视频根本没有字幕：直播、小众频道、新闻网站的录像、网页通话。按下 Live，扩展就会收听当前标签页的音频，识别语音，实时显示原文和译文。在 Google Meet、Zoom、Teams 等浏览器通话中，它会主动提供 Live，而不是显示一个空字幕框。Live 提供 10 分钟免费体验。

我的生词和 Anki 导出

每个保存的单词都会连同它出现的那句话一起留存。保存的单词下次出现在字幕中时会显示金色下划线，可以把它们标记为已掌握，整份单词表也能一键导出到 Anki 或 CSV 表格——都是来自真实视频的真实用法，而不是教科书式的单词表。

适用范围

  • YouTube——带有上传字幕或自动生成字幕的普通视频，以及视频的完整文稿。另见 YouTube 双语字幕。
  • Netflix、Prime Video、Disney+、Max——在播放器中开启原始语言字幕，译文就会显示在下方。详见 Netflix 双语字幕。
  • 在线课程和演讲——课程播放器、TED、Vimeo，以及大多数基于标准 HTML5 视频并带有字幕轨的网站。
  • 你自己的字幕文件——把 .srt 或 .vtt 文件加载到浏览器中的任意视频上。
  • 没有字幕的视频、直播和网页通话——用 Live 翻译标签页的音频。

如果某个网站不需要这个功能，可以在工具栏弹窗中单独关闭该网站，其他网站不受影响。

安装方法：3 步，一分钟搞定

  1. 安装扩展。打开 Chrome 网上应用店中的 LiveSubtitles，点击 添加至 Chrome。在 Microsoft Edge 中，出现提示时允许来自其他应用商店的扩展，再在同一页面安装。
  2. 选择语言。欢迎页会把浏览器的语言设为默认翻译语言，可按需修改，并将图标固定到工具栏。
  3. 打开视频。原文和译文会自动显示在视频下方。这个视频没有字幕？按下 Live 即可。
给语言学习者的小提示：刚开始看的几个视频，可以打开 Q——每行结束后暂停。读完这一行，点击不认识的单词，按 S 再听一遍，然后继续。等大部分内容都能听懂了，再关掉它，正常观看就好。

和其他双语字幕扩展相比

浏览器里的双语字幕并不是什么新鲜概念：Language Reactor、Trancy 和 Immersive Translate 都有各自的实现，如果其中某一个已经满足你的需求，完全没必要换。LiveSubtitles 的不同之处在于：

  • 无需账号，无需登录。安装好即可使用。
  • 免费就是真的免费。双语字幕和查词不限次数，也不会在试用期结束后停止。
  • 没有字幕的视频也能用。Live 会翻译标签页的音频，直播或通话也不会让你两手空空。
  • 不止两个网站。除了 YouTube 和 Netflix，还支持 Prime Video、Disney+、Max、课程播放器和通用的 HTML5 视频。

隐私

没有账号体系。设置和保存的单词都存储在你的浏览器中。字幕文本只在翻译时发送到服务器，且不与你本人关联；标签页音频只在 Live 开启期间、只针对当前标签页使用。扩展不会记录你访问过哪些网站。匿名使用统计可以在设置中关闭。问题反馈：ext@live-subtitles.com。

常见问题

这个扩展免费吗？
免费。双语字幕、字幕翻译和查词都不限次数，也无需账号。Pro 版提供无限 AI 讲解、无限保存单词和导出 Anki；Live 套餐则提供更多小时的实时音频翻译。前 7 天可使用全部功能。

能在 Netflix 上使用吗？
可以。在 Netflix、Prime Video、Disney+ 和 Max 上，扩展会读取平台显示的字幕，并在每一行下面加上译文。只需在播放器中开启原始语言字幕，接下来的工作交给扩展。

如果视频没有字幕怎么办？
按下 Live。扩展会收听当前标签页的音频，识别语音并实时翻译，同样适用于直播，以及浏览器中 Google Meet、Zoom 或 Teams 的网页通话。Live 提供 10 分钟免费体验，之后属于 Live 套餐的一部分。

在 Microsoft Edge、Brave 或 Firefox 中能用吗？
可以在 Google Chrome，以及能从 Chrome 网上应用店安装扩展的 Chromium 浏览器（如 Microsoft Edge 和 Brave）中使用。没有 Firefox 或 Safari 版本；在这些浏览器中，可改用 Live Subtitles 桌面应用，它能翻译电脑上的任意声音。

需要注册账号吗？
不需要。设置和保存的单词都留在你的浏览器中。字幕文本仅在翻译时发送到服务器，标签页音频也只在 Live 开启时才会被使用。

Live Subtitles 应用的订阅包含这个扩展吗？
不包含，扩展有自己独立的免费版本，以及独立的 Pro 和 Live 套餐。大多数人其实不需要付费：双语字幕和查词本身就是免费的。
