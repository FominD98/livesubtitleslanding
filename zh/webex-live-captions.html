Webex 实时字幕与人工智能实时翻译

Cisco Webex 是企业信息技术团队、受监管行业和大型网络研讨会常用的平台，但它的内置字幕往往对参会者不可用，被主持人设置限制，或在免费层账号中完全缺失。Webex 实时字幕改变了这一点。Live Subtitles 会与任意 Webex 会议或网络研讨会并行运行，并直接在你的 Windows 屏幕上显示人工智能实时字幕，无需机器人、无需插件，也无需 Cisco 信息技术部门批准。

如何通过 3 个步骤为 Webex 添加实时字幕

  1. 从 Microsoft Store 下载 Live Subtitles 并启动应用。
  2. 选择“系统音频”作为来源，自动捕获 Webex 音频，无需麦克风。
  3. 加入任意 Webex 会议或网络研讨会，字幕会显示在浮动覆盖层中，并保持在所有窗口之上。

为什么企业 Webex 用户需要独立实时字幕

许多组织在从旧式会议工具迁移后将 Webex 标准化，但会遇到相同的可访问性缺口：Webex 原生人工智能字幕需要特定订阅层级、主持人启用，有时还需要管理员在 Control Hub 中配置。个人参会者，尤其是受监管行业或国际办公室中的人员，往往无法可靠地自行启用字幕。

Live Subtitles 在终端层解决这个问题。由于它读取系统音频，因此完全独立于 Webex 主持人的配置：

  • 没有 Webex 机器人加入会议，也不会出现在参会者列表中。
  • 无需更改 Control Hub 或站点管理员设置。
  • 无需提交 Cisco 信息技术部门工单，从 Microsoft Store 安装应用即可立即使用。
  • 无论主持人的套餐如何，都适用于 Webex Meetings、Webex Webinars 和 Webex Events。

面向国际 Webex 网络研讨会的实时翻译

大型企业网络研讨会经常吸引来自数十个国家的受众。以英语进行的产品发布或全员会，可能有第一语言为日语、西班牙语、德语或阿拉伯语的同事和客户参加。Live Subtitles 的双语字幕模式可以处理这种情况：原始语音显示在上方一行，你选择的译文显示在下方，两者同时出现，没有等待。

这对问答以文本形式进行、参会者无法轻易要求演讲者重复的 Webex Events 尤其有价值。用自己的语言跟上内容可以完全消除这种摩擦。

支持 50 多种语音识别语言和 50 多种翻译目标语言，包括西班牙语、法语、德语、意大利语、日语、中文、韩语、俄语、阿拉伯语、印地语、葡萄牙语、波兰语、荷兰语、土耳其语和乌克兰语。

适用于所有 Webex 会话类型

Live Subtitles 捕获系统音频，因此无需按会话类型进行额外配置，即可用于各种 Webex 会话：

  • Webex Meetings（已安排会议和个人会议室）
  • Webex Webinars 和 Webex Events
  • Webex Training 会话
  • 来自 Webex 应用的一对一和群组通话
  • 在电脑上回放的 Webex 录制会话

浮动覆盖层会保持在 Webex 窗口上方，因此无需切换应用也能始终看到字幕。

适合集中管理型 Webex 环境的实用选择

对于已将 Webex 作为标准视频会议平台推出的企业信息技术团队，员工的可访问性需求并不总是与中央许可或配置保持一致。Live Subtitles 为个人员工提供自助解决方案，不需要组策略更改、不需要虚拟专用网络例外，也不需要在标准 Microsoft Store 应用之外加入已批准软件清单。它完全包含在终端上，不会把会议音频传输给会议主持人或信息技术部门控制的任何服务器，音频会在本地处理，或通过用户自己的语音识别提供方处理。

常见问题

Live Subtitles 可以用于 Webex 会议和网络研讨会吗？
可以。它会在操作系统层捕获系统音频，因此无论主持人设置或订阅层级如何，都可用于任意 Webex 会话。

它需要 Webex 插件或信息技术管理员批准吗？
不需要。Live Subtitles 是独立 Windows 应用，没有 Webex 集成。不需要更改 Control Hub，也不需要 Cisco 信息技术部门批准。

我可以实时翻译 Webex 会议吗？
可以。双语字幕模式会在任意 Webex 会话中同时显示原始语音和你选择的译文语言。

支持哪些语言？
支持 50 多种识别和翻译语言，包括西班牙语、法语、德语、日语、中文、俄语、阿拉伯语、印地语等。
