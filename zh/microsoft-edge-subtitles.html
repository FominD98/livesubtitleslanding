Edge 实时字幕与 AI 浏览器字幕

Microsoft Edge 是每台 Windows 11 电脑上的默认浏览器，也是数十亿小时在线视频、网页会议和播客流的日常入口。Edge 有自己的实时字幕功能，但对多数用户来说只支持英语，不支持翻译，也不一定能在每次浏览器更新后保持一致。通过 Live Subtitles 添加 Edge 实时字幕采用不同方式：它完全位于浏览器之外，用 50 多种语言为 Edge 播放的任何内容加字幕，并提供可选实时翻译，全部显示在一个可停靠到屏幕任意位置的小型浮动覆盖层中。

如何通过 3 个步骤为 Edge 添加实时字幕

  1. 从 Microsoft Store 下载 Live Subtitles 并启动应用。
  2. 选择“系统音频”，无需浏览器扩展即可捕获 Edge 任意标签页中的音频。
  3. 在 Edge 中播放任何视频、音频或网页通话，字幕会立即显示在浮动覆盖层中。

为每个网站加字幕，不只支持热门网站

Edge 内置实时字幕在主流英语视频网站上表现不错，但长尾网页才是字幕最常失效的地方：小语种新闻、地区大学课程门户、小型播客播放器、公司网站上的嵌入式视频和归档广播媒体。Live Subtitles 不关心来源网站。它读取 Windows 通过音频混音器播放的内容，因此 Edge 中任何产生声音的标签页都会以同样方式加字幕：

  • YouTube、Vimeo、Dailymotion 和其他视频平台。
  • 带有任意语言嵌入式视频报道的新闻网站。
  • 大学课程门户和点播课程平台。
  • 网页会议平台，包括 Zoom Web、Meet、Webex 和 Teams 网页客户端。
  • 播客网页播放器和嵌入式音频播放器。
  • 广播和电视直播门户。

无需浏览器插件的多语言网页视频

在网页上观看法语新闻直播、德语时事分析、韩语学术讲座或日语技术会议流，传统上要靠运气，也就是网站恰好有不错字幕，或靠繁琐操作，去网上找 .srt 并手动同步。Live Subtitles 的双字幕模式替代这两者：原始语音显示在上方，译成更熟悉语言的内容显示在下方，两者实时更新，并覆盖在 Edge 播放的任何内容上。

适用于 Edge Workspaces、InPrivate 和分屏

Edge 提供大量高级功能，包括用于共享浏览会话的 Workspaces、垂直标签页、两个标签页并排的分屏、多配置文件和 InPrivate 窗口。这些功能会让基于浏览器扩展的字幕工具不稳定，因为扩展可能无法一致加载。Live Subtitles 不受影响：它是读取同一音频输出的独立 Windows 应用，因此在每个 Edge 功能、每个配置文件和每种窗口模式中都以同样方式工作。

隐私：不访问浏览器数据

因为 Live Subtitles 不是 Edge 扩展，它无法访问你的浏览历史、网站数据、密码或任何其他浏览器端数据。它不能读取标签页 URL，不能看到表单内容，也不能检查页面结构。唯一输入是音频输出流，也就是驱动扬声器的同一条流；唯一输出是显示在你屏幕上的转写文本。支持的识别和翻译语言包括英语、西班牙语、法语、德语、意大利语、日语、韩语、中文普通话、俄语、阿拉伯语、印地语、葡萄牙语、波兰语、荷兰语、土耳其语和乌克兰语，总计 50 多种。

常见问题

Live Subtitles 可以用于 Microsoft Edge 吗？
可以。Edge 中的每个音频来源都可以无需浏览器扩展加字幕。

这和 Edge 内置实时字幕不同吗？
不同。Edge 的功能对多数用户只支持英语；Live Subtitles 支持 50 多种语言和双语翻译。

它会为所有网站加字幕，还是只支持特定平台？
所有网站。任何标签页中播放的音频都会加字幕。

它适用于 Edge InPrivate 和 Edge Workspaces 吗？
可以。字幕可在所有 Edge 配置文件、窗口和模式中同样工作。
