OBS 实时字幕与面向主播的人工智能字幕

使用 OBS 直播已经很自然，但同时跟上游戏音频、共同解说者或国际观众并不总是容易。通过 Live Subtitles 实现的 OBS 实时字幕会提供一个人工智能实时字幕覆盖层，直接与 OBS Studio 并行运行，无需插件。无论你需要监控另一种语言的游戏对白，还是希望在长时间直播中提升自己的可访问性，Live Subtitles 都会在 Windows 音频层透明工作。

如何通过 3 个步骤为 OBS 设置实时字幕

  1. 从 Microsoft Store 下载 Live Subtitles，并与 OBS Studio 一起启动。
  2. 选择“系统音频”来为游戏或桌面音频加字幕，或选择“麦克风”为自己的声音加字幕。
  3. 像平常一样在 OBS 中开始直播或录制，字幕覆盖层会保持显示在你的显示器上，并位于所有窗口之上。

个人字幕覆盖层与直播输出字幕

了解 Live Subtitles 做什么、不做什么很重要，这样你才能判断它是否适合你的设置。Live Subtitles 是个人覆盖层，字幕只显示在你的屏幕上，不会烧录进观众看到的视频输出。这是有意设计的：许多主播希望保留私人的字幕信息流，同时让观众看到干净的直播布局。

如果你希望字幕出现在观众看到的直播输出中，OBS Studio 有自己的内置隐藏字幕插件，可将字幕发送到兼容平台。对于最常见的用途，例如自己监控音频、用第二语言跟随游戏剧情，或在长时间直播中保持专注，Live Subtitles 是更快、更简单的选择。

  • 无需在 OBS 设置面板中安装或配置 OBS 插件。
  • 适用于 OBS 正在捕获的任何音频：游戏音频、浏览器音频、桌面音频。
  • 即使在无边框全屏游戏中，字幕覆盖层也会保持在最上层。
  • 不依赖直播平台接口密钥或第三方服务。

为游戏音频加字幕，并用任意语言监控

主播最常见的用法之一，是为第二语言的游戏音频加字幕。如果你正在直播没有英语配音的日语角色扮演游戏，或在跟随对白密集的游戏剧情，Live Subtitles 可以实时转写和翻译游戏音频。选择“系统音频”，选择源语言（例如日语），把翻译目标设为英语，双语字幕就会显示在屏幕上：上方为原始对白，下方为译文。

这同样适用于队友使用不同语言的合作游戏，也适用于在自己的录制会话旁观看直播回放。支持的识别和翻译语言包括英语、日语、韩语、中文、德语、西班牙语、法语、俄语、葡萄牙语等 40 多种语言。

面向主播的可访问性

可访问性工具通常从观众角度讨论，但主播同样会从中受益。有听力损失或在嘈杂环境中直播的主播，经常会错过音频提示，例如提醒、游戏内语音、Discord 通知，而听力正常的观众可能会立刻捕捉到。Live Subtitles 会把这些音频事件转成可读文本，而不会打断直播流程。

由于覆盖层始终位于最上方且可以完全重新定位，你可以把它停靠在显示器角落，或放在游戏视口下方，避免遮挡界面。对于双显示器设置，你也可以把覆盖层完全移到副屏。

与所有 OBS 功能并行工作

Live Subtitles 不会干扰 OBS 的场景管理、滤镜或编码流程。它从 Windows 混音器层读取音频，因此无论你的 OBS 场景如何配置，它都能独立运行：

  • 适用于 Twitch、YouTube 和任何 RTMP 目标上的直播。
  • 适用于 OBS 中的本地录制。
  • 适用于 OBS Studio 的虚拟摄像头输出。
  • 适用于 OBS 回放缓冲会话。

启动一次 Live Subtitles 并保持运行，整个直播会话都会带上字幕，无需切换场景、无需热键，也无需额外设置。

常见问题

Live Subtitles 可以配合 OBS Studio 使用吗？
可以。它作为独立 Windows 应用与 OBS 并行运行，并在你的显示器上显示浮动字幕覆盖层。无需 OBS 插件。

观众会在我的直播输出中看到字幕吗？
Live Subtitles 默认只在你的显示器上显示字幕。如需让字幕出现在直播输出中，请使用 OBS 的内置字幕插件，或将 Live Subtitles 窗口作为捕获源添加到 OBS 场景。

全屏游戏时它还能工作吗？
可以。覆盖层会保持在所有窗口之上，包括全屏和无边框窗口游戏。

我的观众能看到字幕吗？
默认不能，字幕是个人覆盖层。你可以在 OBS 中把覆盖层窗口捕获为来源，让观众看到它。
