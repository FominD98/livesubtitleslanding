Skype 实时字幕与人工智能实时翻译

尽管更新的平台不断出现，Skype 仍服务于超过 3000 万活跃用户，包括跨洲保持联系的家庭、进行国际客户通话的自由职业者，以及尚未完全迁移到 Teams 的 Skype for Business 企业部署。对他们来说，在 Skype 通话中听懂快速语音或浓重口音可能很困难。Skype 实时字幕可以解决这个问题：Live Subtitles 会与任意通话并行运行，在你的屏幕上显示人工智能实时字幕，无需插件，也无需更改 Skype 账号。

如何通过 3 个步骤为 Skype 添加实时字幕

  1. 从 Microsoft Store 下载 Live Subtitles 并启动应用。
  2. 选择“系统音频”作为音频源，自动捕获 Skype 通话音频。
  3. 拨打或接听 Skype 通话，字幕会自动显示在 Skype 窗口上方的浮动覆盖层中。

为什么 2025 年 Skype 通话仍然需要实时字幕

Skype 内置的实时字幕功能确实存在，但有明显限制：在某些配置中它只会为来电方语音加字幕，要求双方都使用较新的 Skype 版本，并且不支持翻译到任意语言。对于用 Skype 连接不同母语的家庭，例如墨西哥的父母和德国的孩子，或双方都把英语作为第二语言的国际商务通话，这些限制会产生实际影响。

Live Subtitles 的工作方式不同。它读取 Windows 电脑上的系统音频输出，这意味着它会为你听到的一切加字幕，包括对方声音、任何共享屏幕音频，甚至录制消息，而不依赖对方的软件或设置：

  • 无论对方使用哪个 Skype 版本都能工作。
  • 不需要对方更改任何设置。
  • 字幕显示在浮动覆盖层中，并始终保持在 Skype 窗口上方。
  • 支持包含多位发言者的 Skype 群组通话。

面向国际 Skype 通话的实时翻译

许多 Skype 用户依赖该平台进行国际沟通，包括分布在不同国家的家庭、面向海外学生的语言教师，以及跨语言障碍协作的远程工作者。Live Subtitles 的双语字幕模式正是为这种场景设计：原始语音显示在上方一行，你选择的译文语言显示在下方，两者同步实时显示。

乌克兰的祖母可以给加拿大的孙辈打电话，在孙辈说英语时用乌克兰语跟上对话。巴西的自由开发者可以参加英语客户通话，同时阅读葡萄牙语翻译。无需口译员、无需等待，也无需尴尬地要求重复。

支持 50 多种语音识别语言和 50 多种翻译目标语言，包括西班牙语、法语、德语、意大利语、日语、中文、韩语、俄语、阿拉伯语、印地语、葡萄牙语、波兰语、荷兰语、土耳其语和乌克兰语。

在 Teams 迁移期间支持 Skype for Business

许多企业正处于从 Skype for Business（本地部署或在线版）迁移到 Microsoft Teams 的长期过程中。在过渡期，员工可能会同时使用两个平台，或某些部门仍留在 Skype for Business，而其他部门已经迁移到 Teams。Live Subtitles 两者都能覆盖：

  • Skype for Business 本地部署（基于 Lync）的通话
  • Skype for Business Online 会议
  • 消费者版 Skype 语音和视频通话
  • Skype 群组通话和电话会议

由于 Live Subtitles 在操作系统音频层运行，它不需要 Skype for Business 服务器配置，不需要 Exchange 集成，也不需要信息技术部门介入。个人用户可以从 Microsoft Store 安装并立即使用。

无需插件、无需账号更改、无需管理员

Live Subtitles 是一个独立 Windows 桌面应用。它不会在接口层与 Skype 集成，不会以联系人或机器人身份出现在通话中，也不会以任何方式修改 Skype 安装。因此，它适合受监管环境，因为在通信平台中添加第三方集成通常需要合规审查，而 Skype 这一侧根本没有需要审查的内容。

常见问题

Live Subtitles 可以用于 Skype 通话吗？
可以。它会在操作系统层捕获系统音频，因此可用于任意 Skype 语音或视频通话，无需插件或账号更改。

我需要安装 Skype 插件或附加组件吗？
不需要。Live Subtitles 是独立 Windows 应用。不会向 Skype 安装任何内容，也不需要更改 Microsoft 账号。

我可以实时翻译 Skype 通话吗？
可以。双语字幕模式会在任意 Skype 通话中同时显示原始语音和你选择的译文语言。

它适用于 Skype for Business 吗？
可以。它同时适用于消费者版 Skype 和 Skype for Business（本地部署或在线版），无需服务器配置。
