Viber 实时翻译与 AI 通话字幕

Viber 是东欧、巴尔干、菲律宾和东南亚部分地区首选的消息平台，连接着数亿有跨境家庭关系的用户。常见场景很一致：保加利亚的父母给在德国工作的孩子打电话，沙特阿拉伯的菲律宾工人与马尼拉家人通话，乌克兰祖父母联系加拿大的孙辈。这些对话每天都跨越语言边界，而 Viber 并没有内置的语音或视频通话实时翻译。通过 Live Subtitles 添加 Viber 实时翻译可以补齐这个缺口。在 Windows 电脑上与 Viber 一起运行它，你就能获得 50 多种语言的实时字幕和翻译，无需 Viber 插件，也无需更改账号。

如何通过 3 个步骤为 Viber 添加实时翻译

  1. 从 Microsoft Store 下载 Live Subtitles，并与 Viber Windows 版一起启动。
  2. 选择“系统音频”，自动捕获 Viber 通话音频，无需麦克风设置。
  3. 拨打或接听 Viber 通话，字幕和翻译会显示在 Viber 上方的浮动覆盖层中。

东欧跨境家庭通话

Viber 最强的用户基础在东欧，包括俄罗斯、乌克兰、白俄罗斯、保加利亚、罗马尼亚、摩尔多瓦、希腊、捷克、匈牙利和整个巴尔干地区。由于工作迁移，许多对话现在跨越语言：只会俄语或乌克兰语的父母给已在德语、英语、法语或波兰语环境中工作的孩子打电话。Live Subtitles 的双字幕模式直接处理这种场景。上方显示俄语、乌克兰语、保加利亚语或罗马尼亚语原始语音，下方显示译成德语、英语或家庭成员日常使用语言的内容。祖父母可以自然说话，成年亲属一边听原声一边阅读。

菲律宾和东南亚侨民通话

Viber 在菲律宾也占主导地位，并在东南亚广泛使用。在海湾地区、香港、新加坡、美国和欧洲工作的菲律宾工人每天给家里打电话。当第二代孩子在当地语言上比他加禄语或宿务语更流利时，家庭通话就变成双语对话。Live Subtitles 支持菲律宾语/他加禄语、越南语、印尼语、泰语、中文普通话、粤语和韩语等 50 多种语言，覆盖亚洲侨民家庭实际需要的语言组合：

  • 他加禄语/菲律宾语与英语、阿拉伯语或西班牙语配对。
  • 越南语与英语、法语、德语或韩语配对。
  • 印尼语或马来语与英语或普通话配对。
  • 泰语与英语或普通话配对。

群组通话和社区频道

Viber 社区是侨民群体、同乡网络、宗教团体和大家庭圈子的聚集地。社区中的语音消息和音频常常使用母国语言。Live Subtitles 会为 Viber 群组通话、Viber Out 拨打固定电话，以及社区帖子中播放的任何音频消息加字幕，让一个你只能部分听懂音频的社区变成可以完整跟上的社区。

无需 Viber 集成，无需账号权限

Live Subtitles 是独立的 Windows 应用。它不会登录你的 Viber 账号，不会修改 Viber 应用或设置，通话另一方也无法知道你正在使用字幕软件。这意味着你可以把 Live Subtitles 用于敏感家庭对话、商务通话或社区讨论，而无需额外披露。它在功能上就像你边听边戴上阅读眼镜。支持的识别和翻译语言包括英语、俄语、乌克兰语、白俄罗斯语、波兰语、保加利亚语、罗马尼亚语、希腊语、土耳其语、菲律宾语、越南语、印尼语、泰语、中文普通话、粤语、日语、韩语、阿拉伯语、印地语、葡萄牙语、德语、法语、西班牙语和意大利语，总计 50 多种。
