Facebook Live 字幕与 AI 翻译

Facebook 仍然是全球最大的视频舞台，每天有数百万创作者直播，数亿用户观看，Messenger 每月处理数十亿次语音和视频通话。然而 Facebook 的原生字幕并不稳定：它取决于创作者是否开启自动字幕、直播语言是否受支持，以及观众是否使用较新的应用版本。通过 Live Subtitles 添加 Facebook Live 字幕可以补上这个缺口。该应用会为 Windows 电脑上播放的任何 Facebook 音频加字幕，包括 Live 直播、Reels、Watch Party 和 Messenger 通话，支持 50 多种语言，无需插件，也无需创作者配置。

如何通过 3 个步骤为 Facebook 添加实时字幕

  1. 从 Microsoft Store 下载 Live Subtitles 并启动应用。
  2. 选择“系统音频”作为音频来源，捕获浏览器或应用中 Facebook 正在播放的任何内容。
  3. 打开 Facebook Live、Watch Party 或 Messenger，字幕会显示在可任意移动的浮动覆盖层中。

面向关注全球创作者的 Facebook Live 观众

Facebook Live 生态是真正国际化的。越南的小企业可能用越南语直播产品发布；巴西健身教练可能用葡萄牙语带练直播；乌克兰记者可能发布实时现场报道。原生自动字幕能覆盖热门场景，但会漏掉长尾语言，并且当创作者音频混入音乐或环境噪声时常常失效。

Live Subtitles 会绕开这些限制。因为它在系统层为音频加字幕，语言检测基于你实际听到的声音运行。即使创作者从未启用字幕，即使直播语言不在 Facebook 自动字幕范围内，Live Subtitles 也能即时转写并翻译。

Messenger 语音和视频通话

Messenger 是全球使用最广泛的语音和视频通话应用之一，经常连接跨越语言边界的家人和朋友。桌面版 Messenger 没有实时字幕。Live Subtitles 用一种无需 Facebook 权限、无需集成的字幕体验补齐这个空白：

  • 一对一 Messenger 语音和视频通话
  • Messenger 群组通话和 Rooms
  • 从 Facebook 网站或 Messenger 桌面应用发起的通话
  • 在 Messenger 对话中播放的录制语音消息

不同母语者之间的家庭通话尤其适合。父母用他加禄语与在海外生活的孩子通话，或祖父母用另一种语言与孙辈交谈，都可以一边听原声，一边在屏幕上阅读译文，保留真实语音的温度，同时不丢失意思。

50 多种语言的 Watch Party 和群组观看

Watch Party 让朋友们同步观看同一个视频，并在旁边进行语音聊天。Live Subtitles 会同时为两层音频加字幕：视频声音和朋友们的语音评论。因此，多语言小组可以一起观看外语电影，同时继续用语音聊天。因为这是个人覆盖层，每个参与者都能独立选择自己的翻译语言。

支持 50 多种识别语言和 50 多种翻译目标语言，包括西班牙语、法语、德语、意大利语、日语、中文、韩语、俄语、阿拉伯语、印地语、葡萄牙语、波兰语、荷兰语、土耳其语、越南语、印尼语、他加禄语和乌克兰语。

为需要个人字幕监视器的创作者而设

在 Facebook Live 上直播的创作者常常希望监控自己的声音表现，比如节奏、清晰度，以及口音是否可能让非母语观众困惑。在同一台电脑上运行 Live Subtitles，可以为你的声音提供实时文本回显，非常适合及时发现含糊词语或节奏问题。配合标准 Facebook Live 发布工具，它就成为一个轻量的提词和反馈循环。

常见问题

Live Subtitles 可以用于 Facebook Live 直播吗？
可以。无论创作者是否启用原生字幕，任何语言的 Facebook Live 都可以加字幕。

它可以为 Messenger 语音和视频通话加字幕吗？
可以。一对一和群组 Messenger 通话都可以加字幕，无需插件和权限。

我可以实时翻译 Facebook Live 直播吗？
可以。双字幕模式会同时显示原始语音和你的译文语言。

它适用于 Watch Party 音频吗？
可以，共享视频和朋友的语音评论会一起加字幕。
