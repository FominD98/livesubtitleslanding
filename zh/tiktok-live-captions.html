TikTok Live 实时字幕：Windows 人工智能实时字幕

TikTok Live 已经成长为覆盖各种语言和垂直领域的全球创作者舞台，包括烹饪、游戏、健身、音乐和新闻评论。但该平台在 Windows 上没有内置字幕支持。通过 Live Subtitles 实现的 TikTok Live 实时字幕填补了这个缺口：直播开始的瞬间，浮动人工智能字幕覆盖层就会显示在浏览器上方，无需插件，也不需要 TikTok 账号。

如何通过 3 个步骤在 TikTok 上获得实时字幕

  1. 从 Microsoft Store 下载 Live Subtitles 并启动应用。
  2. 选择“系统音频”，这会直接从浏览器捕获 TikTok 音频。
  3. 在浏览器中打开任意 TikTok Live，字幕会自动显示在页面上方的浮动覆盖层中。

用任意语言跟随国际 TikTok 创作者

一些最受欢迎的 TikTok Live 创作者会使用韩语、日语、西班牙语、葡萄牙语和阿拉伯语直播，而许多观众并非这些语言的母语者。Live Subtitles 通过双语字幕模式弥合差距：第一行显示原始口语，第二行显示你选择的译文，两者会随着创作者说话实时更新。

这对观看韩国创作者的美妆和护肤教程、日本厨师的烹饪直播，或西班牙语健身博主的挑战尤其有用。你可以跟上每一步说明，不会漏掉细节。支持 50 多种识别语言和 50 多种翻译目标语言，包括英语、西班牙语、法语、德语、日语、韩语、中文、俄语、阿拉伯语、印地语、葡萄牙语、波兰语、荷兰语、土耳其语和乌克兰语。

通过 TikTok Live 学习语言

TikTok Live 越来越多地被用作沉浸式语言学习工具，创作者会实时主持发音课程、词汇挑战和文化问答。双语字幕可以把被动观看变成主动理解练习。你可以把识别语言设为正在学习的语言，把翻译设为母语，然后随着能力提升逐渐减少对译文行的依赖。

这不仅适用于直播，也适用于录制的 TikTok 视频。由于 Live Subtitles 在 Windows 系统音频层运行，任何在浏览器中播放的 TikTok 内容都会显示字幕，包括短视频、Stories 和 LIVE 回放。

面向 Windows 失聪和听障用户的可访问性

TikTok 会通过移动应用为部分短视频提供自动字幕，但该功能没有扩展到 TikTok Live，也完全不适用于 Windows 浏览器体验。对于在电脑或笔记本上观看 TikTok 的失聪和听障用户，Live Subtitles 提供了一个覆盖所有 TikTok 内容类型的一致实时字幕层。

  • 无论创作者使用哪种语言，字幕都适用于 TikTok Live 直播。
  • 适用于浏览器中播放的 TikTok 视频。
  • 如果已在 Windows 上安装 TikTok 桌面应用，也同样适用。
  • 无需 TikTok 账号集成、接口密钥或浏览器扩展。

Windows 上的 TikTok：浏览器和桌面应用

大多数 Windows 用户通过浏览器访问 TikTok，例如 Chrome、Edge、Firefox，但 TikTok 也有专用的 Windows 桌面应用。Live Subtitles 可同时用于两者，因为它在 Windows 混音器层捕获音频，具体是哪一个应用发出声音并不重要。在 Edge 或桌面应用中打开 TikTok Live，在 Live Subtitles 中选择“系统音频”，字幕就会立即开始。

浮动覆盖层窗口可以调整大小、重新定位并按偏好设置样式。你可以把它放在 TikTok 视频窗口下方阅读字幕，避免遮挡创作者的脸，也可以在多屏设置中停靠到第二显示器。

常见问题

Live Subtitles 可以用于 Windows 上的 TikTok Live 吗？

我可以把 TikTok Live 直播翻译成自己的语言吗？
可以。双语字幕模式会同时实时显示原始语音和你选择的译文。支持 50 多种语言。

它也适用于普通 TikTok 视频吗？
可以。Live Subtitles 可为浏览器中的任何音频加字幕，包括 TikTok 短视频、Stories 和 LIVE 回放。

它适用于 TikTok 桌面应用吗？
可以。它适用于任何产生音频的 Windows 应用，包括 TikTok 桌面应用。
