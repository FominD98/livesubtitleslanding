Android 实时字幕与双语字幕

Live Subtitles 会在你的 Android 手机上以浮动悬浮窗的形式提供 AI 实时字幕和双语字幕 — 覆盖 YouTube、剧集、直播、游戏或任何其他应用。切换到麦克风模式，它还能为房间内发生的对话添加字幕和翻译，对方无需安装任何应用。

为什么 Android 自带的字幕还不够

自 Android 10 起，Android 就提供了设备端实时字幕功能，这确实很有用 — 但它解决的是一个更窄的问题：

  • 没有翻译。Android 的系统字幕功能只会用它听到的语言转录音频，不会翻译成其他语言，也不会同时显示两行文字。
  • 没有麦克风对话模式。它只能为手机播放的内容添加字幕，无法识别站在你面前的人在房间里所说的话。
  • 没有留存内容。没有双语字幕视图，无法在继续阅读原文的同时跟随一部外语视频。

Live Subtitles 是专门为翻译场景而打造的：两种采集模式（系统声音和麦克风）、50 多种语言，并将原文与译文一起显示。

Live Subtitles 为 Android 带来了什么

覆盖任何应用的浮动悬浮窗

一旦授予悬浮窗权限，字幕就会显示在你正在做的任何事情之上 — 在 YouTube、直播或游戏之间切换，字幕依然保持可见，可拖动、可调整大小。

两种音频采集方式

系统声音 通过 Android 的屏幕/音频录制 API 读取手机正在播放的内容 — 视频、游戏、播客、直播。它无法读取通话或语音聊天：无论是普通电话通话，还是通过 WhatsApp、Zoom、Google Meet、Microsoft Teams 或 Discord 等应用拨打的通话，Android 都会特意将这部分音频与媒体播放分开处理。麦克风 模式则专门覆盖这种情况 — 它通过手机麦克风收听，适用于免提通话、面对面对话、讲座，或向导用你不懂的语言讲解。

双语字幕，50 多种语言

在屏幕上同时看到原文和你选择的译文，而不是在翻译完成的那一刻就失去原始措辞。这既有助于理解真正的含义，也有助于在观看过程中学习语言。

可自定义的悬浮窗

字体大小、原文和译文的文字颜色、背景透明度以及屏幕上的位置都可以调整，悬浮窗会在各次会话之间记住你上次放置的位置。

设置：几个步骤，只需一次

  1. 从 Google Play 安装 Live Subtitles。打开应用即可开始免费试用 — 无需账号。
  2. 授予“显示在其他应用上层”权限。应用会在第一次为你打开此 Android 设置页面；打开开关后返回即可。
  3. 选择一个来源。为手机播放的任何内容选择系统声音，或为实时对话选择麦克风。系统声音每次会话都会请求一次 Android 自身的一次性录制确认 — 这是 Android 对所有读取屏幕/音频输出的应用提出的要求，并非 Live Subtitles 添加的内容。
  4. 选择语言并开始。选择所说的语言（或自动检测）以及你的翻译语言，打开双语字幕，悬浮窗就会出现。
系统声音无法采集的内容： WhatsApp、Telegram、Zoom、Google Meet、Microsoft Teams、Discord 等应用中的通话和语音聊天，或手机自带拨号应用中的通话 — Android 会将通话音频与媒体播放分开路由，因此系统声音模式无法读取它。同样的限制也适用于 Netflix、Prime Video、Disney+ 等服务受 DRM 保护的流媒体音频。对于这两种情况，请切换到麦克风模式：将手机对准扬声器（或正在说话的人），Live Subtitles 会改为对听到的内容进行字幕和翻译。

实际使用场景

外语视频和视频博客

观看你正在学习或不懂的语言的 YouTube 视频或直播，在屏幕上同时看到原始音频的文字和译文，而不必依赖平台自带的自动生成字幕。

直播、播客和录制讲座

直接通过系统声音为 Twitch 或 YouTube Live 直播、播客节目，或录制的讲座、课程视频添加字幕并翻译，不受平台自身自动字幕或缺少翻译功能的限制。

旅行、通话和面对面交流

切换到麦克风模式，实时获取附近有人说话内容的翻译文本 — 点餐、问路、跟随向导，或接听免提通话 — 无需来回传递手机使用另一个翻译应用。

随时随地学习语言

双语字幕让你在看着译文出现的同时阅读原文，这是从真实内容中学习词汇和句子结构的常用方法。

获得更好效果的小技巧

  • 提前一次性授予悬浮窗权限 — 应用会自动请求该权限，但提前在设置中手动授予可以避免会话中出现多余的一步。
  • 在你知道源语言时明确指定它；自动检测会稍微增加延迟，并可能混淆相近的语言。
  • 将应用排除在激进的电池优化名单之外，尤其是在那些会强行终止后台前台服务的手机上（某些厂商定制的 Android 系统中较常见），以免会话中断。
  • 对于受 DRM 保护的流媒体应用，使用麦克风模式而非系统声音，因为它们的音频无法直接被采集。

常见问题

如何允许应用在其他应用上层显示字幕？
你第一次开始会话时，Live Subtitles 会自动为你打开“显示在其他应用上层”权限页面 — 打开开关即可。你也可以在 Android 设置 > 应用 > Live Subtitles > 显示在其他应用上层 中手动设置（不同手机品牌的命名可能略有不同）。

支持哪些 Android 版本和手机？
Android 10（API 级别 29）及更高版本，可在任何厂商的手机上运行 — 所使用的悬浮窗和音频录制 API 都是标准的 Android 接口，而非特定品牌功能。

我需要联网吗？
需要。语音识别和翻译都在云端运行，因此需要稳定的网络连接。没有离线模式。

它能在 Netflix、Prime Video 或其他流媒体应用中使用吗？
系统声音模式可以采集大多数应用的音频 — YouTube、浏览器、游戏、播客、直播。Netflix、Prime Video、Disney+ 等服务受 DRM 保护的音频，出于设计原因会被 Android 针对任何录制操作静音。请切换到麦克风模式并将手机对准扬声器，依然可以获得字幕。

它能翻译 WhatsApp、Zoom、Teams 或普通电话通话吗？
通过系统声音无法做到。Android 会将通话和语音聊天音频与媒体播放分开处理，因此系统声音模式无法读取它 — 无论是普通电话通话，还是通过 WhatsApp、Telegram、Zoom、Google Meet、Microsoft Teams 或 Discord 拨打的通话。请切换到麦克风模式，让它通过手机麦克风收听。

它能为面对面的实时对话添加字幕吗？
可以 — 麦克风模式会转录并翻译房间内发生的对话，适用于旅行、免提通话，或与不会说你的语言的人交流。

它支持多少种语言？
支持 50 多种语言的翻译，并通过双语字幕同时显示原文和译文。

有免费试用吗？
有。新安装会附带免费试用额度，无需信用卡。订阅和一次性分钟数包之后可在应用内和 Google Play 页面上购买。

为什么使用时 Android 会显示通知？
在后台录制音频需要前台服务，Android 会在该服务运行期间显示持续通知。这是标准提示，并不意味着有额外的录制行为。

它能区分不同的说话人吗？
不能。它会显示原始语音及其翻译，但不会标记或区分说话人。
