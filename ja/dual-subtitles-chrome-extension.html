二重字幕Chrome拡張機能 — YouTube・Netflix対応

Chrome版のLiveSubtitlesは、ブラウザ内のあらゆる動画の下に2行の字幕——原文とあなたの言語への翻訳——を表示します。単語をクリックすれば意味がわかり、Anki用に保存でき、字幕が一切ない動画では音声をライブで翻訳します。二重字幕と単語検索は無料で、1日の制限もアカウントも不要です。

Chromeに追加 — 無料

Google Chrome、Microsoft Edge、Braveで利用できます。Windows、Mac、iPhone、Android向けLive Subtitlesアプリの開発チームによる提供です。

拡張機能の機能

すべての動画に2行の字幕

原文の行が上、翻訳がその下に表示されます。フォント、サイズ、色、位置はお好みで設定可能です。拡張機能はサイトにすでにある字幕——YouTubeのアップロード字幕や自動生成字幕、NetflixやPrime Videoの字幕、オンライン講座プレーヤーのトラック、ほとんどのHTML5動画——を読み取り、表示されるたびに各行を翻訳します。動画の言語は自動検出され、39言語に翻訳できます。自分のファイルを使いたい場合は、.srtや.vttの字幕ファイルをどの動画にも読み込めます。

単語をクリックして学習

字幕中の単語にカーソルを合わせるかクリックすると、文脈に沿った翻訳、辞書の意味、発音、例文を示すカードが開きます。複数の単語をドラッグすれば、フレーズやイディオム全体を翻訳できます。それでも意味がわからないときは、AIで解説が文法やイディオム、スラングをあなたの言語で説明します。聞いている間は話されている単語がハイライトされるので、耳と目が同じ場所を追えます。

動画の横にインタラクティブな文字起こし

文字起こしを開くと、動画全体をテキストとして、翻訳付きで行ごとに確認できます。検索したり、行をクリックしてその場面に戻ったりでき、学習用キーも使えます：A前の行、S繰り返し、D次の行、Q各行の後で一時停止。内容の濃い講義や、半分しか理解できなかったシーンを読み解く一番速い方法です。

字幕がないときのライブ翻訳

ライブ配信、小規模チャンネル、ニュースサイトの録画、ウェブ通話など、字幕が一切ない動画はたくさんあります。Liveを押すと、拡張機能が現在のタブの音声を聞き取り、発話を認識して原文と翻訳をリアルタイムで表示します。Google Meet、Zoom、Teamsなどブラウザでの通話では、空の字幕ボックスを出す代わりに自動でLiveを提案します。Liveは無料で10分間お試しできます。

単語帳とAnkiエクスポート

保存した単語には、その単語が出てきた文がそのまま残ります。保存した単語は次に字幕に現れたとき金色の下線で表示され、習得済みにすることもでき、リスト全体をワンクリックでAnkiやCSV形式のスプレッドシートに書き出せます——教科書の単語リストではなく、実際の動画から得た本物のフレーズです。

対応先

  • YouTube——アップロード字幕や自動生成字幕のある通常の動画、動画全体の文字起こしにも対応。詳しくはYouTube二重字幕をご覧ください。
  • Netflix、Prime Video、Disney+、Max——プレーヤーで原語の字幕をオンにすると、その下に翻訳が表示されます。詳しくはNetflix二重字幕をご覧ください。
  • オンライン講座や講演——講座プレーヤー、TED、Vimeo、そして字幕トラックを持つ標準的なHTML5動画のほとんどのサイト。
  • 自分のファイル——ブラウザ内のどの動画にも.srtや.vttファイルを読み込めます。
  • 字幕のない動画、ライブ配信、ウェブ通話——タブの音声を翻訳するLiveで対応。

不要なサイトがあれば、ツールバーのポップアップからそのサイトだけ拡張機能をオフにできます。他のサイトではそのままオンの状態が続きます。

インストール方法：3ステップ、1分

  1. 拡張機能を追加します。Chrome Web StoreのLiveSubtitlesを開き、Chromeに追加を押します。Microsoft Edgeでは、確認を求められたら他のストアからの拡張機能を許可し、同じページからインストールします。
  2. 言語を選びます。ウェルカムページでは、ブラウザの言語が翻訳先の言語として提案されます。必要に応じて変更し、アイコンをツールバーに固定してください。
  3. 動画を開きます。原文と翻訳が自動的にその下に表示されます。この動画に字幕がない場合は、Liveを押してください。
語学学習者へのヒント：最初の数本の動画ではQ — 各行の後で自動一時停止をオンにしてみましょう。行を読み、知らない単語をクリックし、Sを押してもう一度聞き、次へ進みます。ほとんどの行が聞き取れるようになったらオフにして、普通に視聴しましょう。

Live SubtitlesはWindowsとMac向けのアプリとして始まり、用途によってはいまもアプリが最適な選択です。要約すると、拡張機能はブラウザ内の動画視聴と単語学習向け、アプリはパソコン上のあらゆる音声向けです。

他の二重字幕拡張機能との違い

ブラウザでの二重字幕はよく知られた方法で、Language Reactor、Trancy、Immersive Translateもそれぞれの形で対応しています。すでにそのどれかで満足しているなら、乗り換える理由はありません。LiveSubtitlesならではの違いは次のとおりです。

  • アカウント不要、サインイン不要。インストールすればすぐ使えます。
  • 無料は本当に無料。二重字幕と単語検索には1日の制限がなく、お試し期間が終わっても止まりません。
  • 字幕のない動画にも対応。Liveがタブの音声を翻訳するので、配信や通話で何も表示されないということがありません。
  • 対応は2サイトだけではありません。YouTubeとNetflixに加え、Prime Video、Disney+、Max、講座プレーヤー、一般的なHTML5動画でも使えます。

デスクトップツールを含めたより広い比較は、Language Reactorの代替とおすすめの二重字幕アプリをご覧ください。

プライバシー

アカウントはありません。設定と保存した単語はブラウザ内に保存されます。字幕テキストは翻訳のためだけにサーバーへ送信され、あなた個人とは紐づけられません。タブの音声はLiveがオンの間、そのタブについてのみ使用されます。拡張機能は訪問サイトの記録を取りません。匿名の利用統計は設定でオフにできます。ご質問はext@live-subtitles.comまで。

よくある質問

拡張機能は無料ですか？
はい。二重字幕、字幕翻訳、単語検索は1日の制限なし・アカウント不要で無料です。Proでは無制限のAI解説、無制限の単語保存、Ankiエクスポートが使えます。Liveプランではライブ音声翻訳の時間が追加されます。最初の7日間はすべての機能が使えます。

Netflixで使えますか？
はい。Netflix、Prime Video、Disney+、Maxでは、拡張機能がサービス側で表示される字幕を読み取り、その下に翻訳行を追加します。プレーヤーで原語の字幕をオンにすれば、あとは拡張機能が処理します。

動画に字幕がない場合は？
Liveを押してください。拡張機能が現在のタブの音声を聞き取り、発話を認識してリアルタイムで翻訳します。ライブ配信や、ブラウザでのGoogle Meet、Zoom、Teamsの通話でも使えます。Liveは無料で10分間お試しでき、その後はLiveプランの対象になります。

Microsoft Edge、Brave、Firefoxで使えますか？
Google Chromeと、Chrome Web Storeからインストールできるchromium系ブラウザ（Microsoft EdgeやBraveなど）で使えます。FirefoxやSafari版はありません。これらのブラウザではLive Subtitlesデスクトップアプリをご利用ください。パソコン上のあらゆる音声に対応しています。

アカウントは必要ですか？
いいえ。設定と保存した単語はブラウザ内に残ります。字幕テキストは翻訳のためだけにサーバーへ送信され、タブの音声はLiveがオンの間だけ使用されます。

Live Subtitlesアプリのサブスクリプションに拡張機能は含まれますか？
いいえ、拡張機能には独自の無料プランと、独自のProおよびLiveプランがあります。多くの方は支払いが不要です。二重字幕と単語検索は無料だからです。
