Windows 10・11向け字幕

リアルタイム字幕：パソコンで聞こえる言葉を、すべて文字で

ビデオ通話、映画、講義、近くにいる人の話——Live Captionsは話された内容を約1秒で大きな文字に変換します。話者ごとに色分けされます。

無料でダウンロード

無料の利用時間でスタート · カード登録不要 · Microsoft Store

音が出るものなら何にでも対応します: Zoom Microsoft Teams Google Meet WhatsApp Telegram YouTube 映画や講義

3ステップで字幕が読めます

面倒な設定や予備のデバイスは不要です。Zoomやブラウザに何かを追加インストールする必要もありません。

1

Live Captionsを開く

Microsoft Storeからインストールして開きます。字幕ウィンドウが他のアプリの上に表示されます。

2

聞き取る音声を選ぶ

通話や動画にはパソコンの音声を、同じ部屋にいる人にはマイクを選びます。

3

「開始」を押して読む

話されている内容がリアルタイムで字幕に表示されます。いつでも一時停止でき、利用時間は字幕が表示されている間だけ消費されます。

役立つ場面

パソコンの音声やマイクの音を聞き取り、約1秒以内に話されている内容を大きな文字で表示します。特定のアプリだけでなく、パソコン全体の音に字幕を付けられます。

ビデオ通話

Zoom、Microsoft Teams、Google Meet、WhatsApp、Telegramの通話内容を、聞き返すことなく目で追えます。通話にボットなどが参加することはなく、字幕は自分にしか見えません。

動画、映画、テレビ番組

YouTube、映画、テレビ配信、ポッドキャスト、ウェビナー、オンライン講義などに字幕を表示します。動画自体に字幕が付いていない場合でも利用できます。

同じ部屋にいる人の声

マイクに切り替えれば、隣にいる人が話す内容も読めます。病院での診察時、授業中、家族との食卓などで役立ちます。

読みやすく作られています

大きなボタン、わかりやすい言葉、目を凝らさなくていい文字。

大きくて見やすい文字

文字サイズは最大64ptまで必要に応じて拡大できます。ウィンドウは自由に移動・サイズ変更でき、例えば動画の下に配置することもできます。

ライト、ダーク、ハイコントラスト。目に優しい配色と文字色を選べます。

文字起こしの履歴

セッションごとにパソコンへ保存されます。さかのぼって表示したり、単語で検索したり、話者名を変更したり、テキストをコピーしたり、TXTやSRT形式で書き出したりできます。

  • 話者ごとに色分けして改行表示
  • 60言語に対応、言語は自動検出
  • ウィンドウは常に最前面、クリックは通り抜けます

率直なお答え

インストール前によく聞かれることです。

無料で試す

無料の利用時間から始められ、カード登録は不要です。その後は利用時間パックかサブスクリプションです。

音声は録音されません

字幕の表示中、音声は音声認識サービスに送られます。履歴はご自身のパソコンにのみ保存されます。

インターネットが必要です

音声認識はオンラインで動作します。マイクは近くにいる人のためだけに必要です。

字幕表示のみです

Live Captionsは話されている内容を、話されている言語のまま文字にします。翻訳は行いません。

こんな方におすすめです

字幕は耳の聞こえにくい方だけのものではありません。音が聞き取りにくいとき、早口なとき、一言も聞き逃したくないとき、画面の文字は誰にとっても助けになります。

仕事で

会議や取引先との電話で、聞き返す必要がなくなります。あとからフレーズを検索して、テキストを保存することもできます。

学校や大学で

講義やウェビナー、オンライン講座では、メモを取る代わりに内容に集中でき、文字起こしをTXTで保存できます。

語学学習中の方

英語やドイツ語など、学習中の言語の動画やポッドキャスト、通話も、元の言語の字幕があれば理解しやすくなります。

音量を上げられないとき

子どもが寝ている、オフィスにいる、イヤホンが手元にない——そんなときは音量を下げて字幕を読めます。

聞き取りにくいとき

小さな声、早口、訛り、回線の悪さ——話し言葉が文字になれば、聞き逃しません。

耳の聞こえにくい方とご家族

聞き取ろうと無理をせず、通話や動画を文字で読めます。ご両親に設定してあげれば、また家族のビデオ通話に参加できるようになります。

よくある質問

Windows 11に標準搭載のライブキャプションとの違いは?
標準機能は無料ですが、Windows 11でのみ動作し、対応言語はWindowsのバージョンによって限られます。Live CaptionsはWindows 10でも動作し、60言語に対応して言語を自動で判別します。話者ごとに異なる色で改行して表示し、検索できる履歴をTXTやSRTで書き出すこともできます。また、文字サイズは最大64ptまで大きくできます。
Zoom、Teams、WhatsApp、YouTubeでも使えますか?
はい。Live Captionsはパソコンが再生する音声を聞き取るため、Zoom、Microsoft Teams、Google Meet、WhatsApp、Telegramの通話、YouTube、映画、テレビ配信、オンライン講義など、どのアプリでも利用できます。それらのアプリに何かをインストールする必要はなく、通話にボットなどが参加することもありません。
通話相手に字幕は見えますか?
いいえ。字幕はご自身の画面にのみ表示されます。相手に通知が届くことも、何かが見えることもありません。
Live Captionsは翻訳もできますか?
いいえ。Live Captionsは話されている内容を、話されている言語のまま文字にします。音声を読むためのアプリであり、翻訳するためのものではありません。
料金はいくらですか?
カード登録なしの無料分から始められます。その後は、買い切りの利用時間パックを購入するか、月額または年額のサブスクリプションを選べます。利用時間は字幕を表示している間だけ消費されます。 すべての料金を見る.
音声は録音されますか?
音声を録音したり保存したりすることはありません。字幕の表示中、音声はテキスト化のために音声認識プロバイダーへ送信されます。テキストの履歴はご自身のパソコンにのみ保存され、削除することもできます。詳しくはプライバシーポリシーをご覧ください。
利用するには何が必要ですか?
Windows 10またはWindows 11搭載のパソコンと、インターネット接続が必要です。マイクは、同じ部屋にいる人の話を字幕で読みたい場合にのみ必要です。
